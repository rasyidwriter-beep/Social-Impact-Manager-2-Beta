# JEJAK ACEH — The Living Heritage

Prototype game petualangan budaya Aceh berbasis web, dengan kamera top-down dan visual pixel-art.

## Cara menjalankan
Buka `index.html` melalui browser modern (Chrome, Edge, Firefox). Dapat dimainkan di desktop dan browser mobile.

## Kontrol
- Desktop: WASD / tombol panah untuk bergerak, F atau Space untuk berinteraksi, Esc untuk menutup panel.
- Mobile: joystick virtual, tombol ✦ untuk berinteraksi, tombol jurnal untuk membuka catatan.

## Isi prototipe
- Area awal Gampong Pusaka (desa fiktif yang terinspirasi dari suasana kampung Aceh).
- NPC dengan dialog pengantar.
- Tiga objek pengetahuan awal: Rumoh Aceh, rencong, dan kerajinan.
- Jurnal budaya untuk menyimpan penemuan.

## Batasan versi 0.1
Ini prototipe web awal, bukan APK Android dan belum merupakan game final. Peta, animasi, quest, penyimpanan progres, serta materi budaya masih perlu dikembangkan. Validasi deskripsi budaya dengan sumber lokal/ahli dan komunitas Aceh diperlukan sebelum publikasi edukasi.

## Struktur
- `index.html` — game satu halaman (HTML, CSS, JavaScript Canvas).
