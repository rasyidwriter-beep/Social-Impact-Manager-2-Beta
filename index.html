🎮 Cara Bermain

  • Gerak Karakter: Gunakan tombol W A S D atau Panah di Desktop, atau Virtual D-Pad di Smartphone.
  • Interaksi: Dekati warga (NPC) atau pintu bangunan lalu tekan E / Spasi atau tombol AKSI.
  • Manajemen Keuangan: Anda memulai dengan dana Rp 12.000.000. Setiap program memiliki biaya, durasi hari pengerjaan, dan trade-off. Jangan habiskan seluruh likuiditas tanpa cadangan darurat!
  • Zakat Produktif & ZISWAF: Kunjungi Masjid Al-Barakah atau Kantor Lembaga untuk menggalang dana ZISWAF. Program pemberdayaan ekonomi menghasilkan dampak berkelanjutan setiap hari.

🚀 Langkah Publikasi ke GitHub Pages

  1. Buat repository baru di GitHub bernama social-impact-manager.
  2. Simpan halaman ini sebagai index.html (atau klik tombol unduh di bawah) dan unggah ke repository.
  3. Buka menu Settings → Pages pada repository GitHub Anda.
  4. Pada bagian Build and deployment (Branch), pilih branch main dan folder / (root), lalu klik Save.
  5. Game Anda akan langsung aktif dan dapat dimainkan di https://username.github.io/social-impact-manager/.
